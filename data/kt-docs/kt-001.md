# Knowledge Transfer — Aarav Mehta (Payments Platform)

## System Overview
The Payments Microservices Platform consists of four Spring Boot services:
`payment-orchestrator`, `ledger-service`, `refund-worker`, and the
`payments-bff`. They communicate over REST and an internal Kafka topic
(`payments.events`). Data is stored in PostgreSQL (`paydb`) with read replicas.

## Architecture Notes
- `payment-orchestrator` is the entry point; it coordinates authorization,
  capture, and settlement via a state machine.
- Idempotency is enforced using a Redis-backed idempotency key store.
- The Acme Retail client portal calls the BFF, never the services directly.
